# Особое семейное положение — макеты

Интерактивные HTML-макеты веб-сервиса «Цифровой AI-навигатор поддержки семей с детьми с ОВЗ, инвалидов, опекунов и попечителей» для Иркутской области.

## Быстрый просмотр

- Откройте `index.html` — это навигация по всем 19 экранам.
- PDF-альбом для согласования: [`pdf/Особое_семейное_положение_макеты.pdf`](pdf/).

## Состав

- `index.html` — обзорная навигация
- `01-landing.html` … `19-admin-unanswered.html` — отдельные экраны
- `assets/shared.css` — дизайн-токены и общие стили
- `assets/icons.js` — SVG-иконки
- `assets/partials.js` — общие элементы (сайдбары, шапки)

## Что показано

**Публичная зона:** лендинг, вход, регистрация, онбординг профиля.
**Пользовательская зона:** главная, чат с навигатором, документы (загрузка и результат), каталог рекомендаций, деталь меры поддержки, карта организаций (2GIS), карточка организации, профиль семьи, история обращений, настройки.
**Административная зона:** дашборд, база знаний, статистика, вопросы без ответа.

## Замечания для проверки

- Карты 2GIS на макетах — статические превью, в реальной реализации будут интерактивными через MapGL JS API.
- Шрифты SB Sans Display/Text заменены на Inter в макетах (в продакшен-сборке используется SB Sans).
- Светлая тема. Только русский язык. Регион — Иркутская область.
- Адаптив проверяется уменьшением окна браузера (контрольная точка — 768px).
